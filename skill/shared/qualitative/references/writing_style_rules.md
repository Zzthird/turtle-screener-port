# 写作风格规范（权威文件 · 杠杆8）

> 所有定性分析 Agent 共享。本文件是**唯一权威**的写作风格来源；`agents/writing_style.md` 已收缩为指针。
> 目标：叙述必须**配得上数字**——每句判断由具体数值 + 基准 + 口径支撑，杜绝空洞形容词。

## 一、核心 10 条

1. **结论先行**：每个维度以**一句加粗结论**开头，论证在后。
2. **Lead with numbers（数字先行）**：先给数字再给形容，且数字须带基准与口径。
   - ✅「营收增长 15% 至 405.29 亿元（同比，合并口径）[src: CM§2]」
   - ❌「营收增长强劲」「盈利能力显著提升」
3. **重点突出**：关键数据和评级用**加粗**，避免淹没在长段落中。
4. **格式选择**：结构化对比用表格，因果推理用段落；不要把所有内容堆进表格。
5. **逻辑过渡**：段落之间保持清晰的因果/递进，避免信息跳跃。
6. **去重**：维度之间不重复引用同一数据；交叉引用时简短提及（"如 D2 所述"）。
7. **通俗表达**：用通俗语言解释术语，让非专业读者也能理解核心逻辑。
8. **溯源标注**：支撑评级的每个财务数字必须带 `[src: ...]`（语法见 `qualitative_assessment.md` 溯源标注语法）。
9. **不越界**：推断写成"推断/估计"，不得写成既定事实；法律/监管定性措辞受第四节约束。
10. **利润口径**：默认 GAAP 归母净利润（除非 preflight/coordinator 指定其他口径），并在首次出现时标口径。

## 二、单位规范（★ 变更，取代旧 writing_style.md 第 7 条）

| 场景 | 单位 | 来源 |
|------|------|------|
| **报告正文**（叙述、执行摘要、维度分析） | **亿元**，2 位小数，千位逗号 | 一律引用 **CM§1** 的亿元值，**禁止**从百万元自行心算换算 |
| **结构化参数表**（output_schema 参数） | **百万元**（下游 schema 兼容，勿改） | data_pack §N |
| **数据文件**（data_pack_market.md / computed_metrics.md 原值列） | **百万元** | Tushare 原值 ÷ 1e6 |

> 旧规则"金额单位：百万元"仅适用于参数表与数据文件；**正文改用亿元**，且亿元值必须来自 CM§1。
> 这条变更直接消除"母公司权益 77.5 亿 vs 774.59 亿"一类单位换算 bug——正文不再做换算，只引用。

## 三、模糊量化词禁用表

下列词单独出现即为不合格，必须替换为「数值 + 基准对象 + 口径」：

| 禁用词 | 必须改为（模板） |
|--------|-----------------|
| 大幅 / 显著 / 明显（增长/下滑） | 「+X%（同比，口径）」或「从 A 亿降至 B 亿」 |
| 较好 / 优异 / 强劲 | 「ROE X%，高于行业中枢 Y%」 |
| 优于行业 / 领先同业 | 「毛利率 X% vs 可比公司 均值 Y%（列出对手）」 |
| 高 / 低（估值/负债） | 「PE X 倍 vs 近 5 年区间 A–B 倍」「有息负债率 X%」 |
| 大量 / 充裕 / 紧张 | 「货币资金 X 亿，覆盖 Y 倍短债」 |
| 大幅提价 / 有定价权 | 「过去 5 年 N 次提价，累计 +X%」 |

## 四、术语统一表

| 统一用词 | 避免混用 |
|---------|---------|
| 归母净利润 | 净利润（少数股东）、股东应占溢利（港股正文首现标注一次即可） |
| 营业收入 / 营收 | 销售额、营业额 |
| 分红支付率 | 派息率、分红率（正文统一"分红支付率"） |
| 毛利率 / 净利率 | 毛利、利润率（须指明毛/净） |
| 有息负债 | 借款、负债（区别于总负债） |
| 自由现金流(FCF) | 现金流（须指明 OCF/FCF/自由现金流） |

## 五、法律/监管措辞黑名单（不越界）

| 禁用（除非有生效监管结论） | 改为 |
|---------|------|
| 违规 / 造假 / 舞弊 / 操纵 | 争议 / 嫌疑 / 待监管结论 / 会计政策变更 |
| 隐瞒 / 欺诈 | 披露不充分 / 信息不对称（并注明依据） |
| 事后承认 xx | 追溯调整 / 前期差错更正（按公告原始定性表述） |
