# 东财 push2 接口逆向笔记（实测）

> 用于筛选器获取**全市场 PE/PB/市值/股息率**快照（Tushare 免费版拿不到）。

---

## 一、可用组合（三个条件缺一不可）

| 条件 | 值 | 说明 |
|---|---|---|
| **域名** | `82.push2delay.eastmoney.com` | `push2`/`82.push2` 被风控；**delay 域名最宽松** |
| **Cookie** | 必需 | 关键是 `st_pvi` / `st_nvi`（反爬令牌），浏览器访问东财页面时下发 |
| **代理** | 走系统代理 | 直连 → `RemoteDisconnected`；走代理才通 |

**备选域名**：`push2delay.eastmoney.com`、`82.push2.eastmoney.com`、`2.push2.eastmoney.com`

---

## 二、请求参数

```
GET https://82.push2delay.eastmoney.com/api/qt/clist/get
  ?pn=1              # 页码
  &pz=200            # 每页条数（>200 易 502）
  &fs=<市场>          # 见下
  &fields=<字段>      # 见下
```

**市场（fs）**：
```
m:0+t:6           深主板
m:0+t:80          创业板
m:1+t:2           沪主板
m:1+t:23          科创板
m:0+t:81+s:2048   北交所
（逗号拼接，或用单一市场降低 502 概率）
```

**⚠️ 不要带 `fltt=2`**：带上会导致返回格式/值域变化。**不带 fltt 时值为 x100 整数，需 ÷100**。

---

## 三、字段映射（重要）

| f 码 | 含义 | 缩放 |
|---|---|---|
| `f2` | 最新价 | **÷100** |
| `f8` | 换手率(%) | 原值 |
| `f9` | PE(TTM) | **÷100** |
| `f12` | 代码（无后缀） | — |
| `f14` | 名称 | — |
| `f20` | 总市值（元） | 原值 |
| `f21` | 流通市值（元） | 原值 |
| `f23` | PB | **÷100** |
| **`f37`** | **股息率(%)** | 原值 |

**验证基准**（用于确认字段未错位）：
```
平安银行 000001: PE 4.31 / PB 0.48 / 股息率 5.22%
万科A    000002: PE 负 / 股息率 -13.65%
```

---

## 四、返回结构

```json
{"rc":0, "data":{
   "total": 5923,
   "diff": {                  // ⚠️ 可能是 dict（分页模式）或 list（非分页）
     "0": {"f9":431, "f12":"000001", "f14":"平安银行", "f20":..., "f23":48}
   }
}}
```

**必须兼容两种 `diff` 类型**。

---

## 五、故障模式

| 现象 | 含义 | 处理 |
|---|---|---|
| `RemoteDisconnected` | 风控（缺 Cookie / 直连 / 域名不对） | 换域名/Cookie/走代理 |
| **HTTP 502**（559 字节 HTML） | **服务端故障** | **不触发冷却**，跳过该页继续 |
| 返回非 JSON | 风控页或网关错误 | 显式报错，不要 `.json()` 硬解析 |
| 分页中断（拿到 500/5923） | 单页失败 | 容忍 1 次，连续 2 次才放弃 |

## 七、Cookie 获取方式

**自动**（不确保成功）：访问东财页面拿 Set-Cookie。

**手动**（可靠）：
1. 浏览器打开 `https://82.push2delay.eastmoney.com/api/qt/clist/get?...`
2. F12 → Network → 右键该请求 → **Copy as cURL**
3. 从 cURL 里提取 `-b '...'` 部分
4. 存到 `output/.em_cache/cookie.txt`

---

## 八、限制与教训

- **必须遵守探测纪律**（见系统 AGENTS.md）：间隔 ≥5s、成功即停、累计 ≤5 次
- 本文档的结论来自**反复探测**，曾两次把接口探挂（含用户浏览器也不能访问）
- **正确做法**：拿到一次成功结果就固化配置，不要为"确认稳定性"反复测
