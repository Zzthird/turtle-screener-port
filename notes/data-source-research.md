# 数据源平替调研（Tushare 替代）

调研目的：龟龟框架依赖 Tushare Pro（需积分/付费），寻找免费替代。

---

## 一、框架实际依赖的 Tushare 接口（实测扫描）

从 `scripts/tushare_modules/` 扫描出的**完整依赖清单**（22 个接口）：

### A股（核心，不可缺）
```
income            利润表          ★核心
balancesheet      资产负债表       ★核心
cashflow          现金流量表       ★核心
fina_indicator    财务指标         ★核心
daily             日线行情         ★核心
daily_basic       每日指标(PE/PB/市值) ★核心
weekly            周线（10年历史价格）★核心
dividend          分红历史         ★核心
fina_audit        财务审计意见
fina_mainbz       主营业务构成
top10_holders     十大股东
pledge_stat       股权质押
repurchase        股份回购
stock_basic       股票基础信息
trade_cal         交易日历
yc_cb             国债收益率曲线（Rf）
```

### 港股
```
hk_daily  hk_basic  hk_income  hk_balancesheet  hk_cashflow  hk_fina_indicator
```

### 美股
```
us_daily  us_basic  us_income  us_balancesheet  us_cashflow  us_fina_indicator
```

### Tushare 积分门槛（关键约束）
| 积分 | 频次 | 可用接口 | 价格 |
|---|---|---|---|
| 120 | 50/分, 8000/天 | **仅非复权日线** | 免费 |
| 2000+ | 200/分, 10万/天 | 财务等常规接口 | ~200 元/年 |
| 5000+ | 500/分 | 常规数据无上限 | ~500 元/年 |

> ⚠️ **结论：免费 120 积分** 只能拿日线，**三大报表全拿不到**。龟龟框架**必须付费**（至少 2000 积分）才能跑 A 股。这是找平替的根本动机。

## 二、四个候选（用户指定）

### 1. AkShare
| 项 | 内容 |
|---|---|
| 注册 | 否 |
| 财务三表 | ✅ `stock_financial_report_sina`（资产负债表/利润表/现金流量表，新浪源） |
| 分红/股东 | ✅ |
| 本质 | **爬虫集合**（东方财富/新浪/腾讯等） |
| 致命缺点 | 上游页面改版 → 接口**间歇性失效**；字段命名不统一；东财源**并发批量会被限流封禁** |
| 覆盖 | 最广（股/基/期/宏观/另类） |

**适配可行性**：中。需写映射层（字段名与 Tushare 完全不同），且要处理偶发失效。

### 2. Baostock
| 项 | 内容 |
|---|---|
| 注册 | 否 |
| 财务数据 | ⚠️ 只有**季频衍生指标**（`query_profit_data` 盈利能力 / `query_balance_data` 偿债 / `query_cash_flow_data` 现金流 / `query_dupont_data`），**没有完整三大报表** |
| 复权 | ✅ 复权因子完整 |
| 退市股 | ✅ 保留完整 |
| 延迟 | 行情延迟较大（约 1 天） |
| 定位 | **专为 A 股回测设计** |

**适配可行性**：**低**。龟龟框架要的是**完整三表逐行数据**（应收账款、预收款、折旧摊销、少数股东损益等），Baostock 只有汇总指标，**关键字段缺失**，无法支撑穿透回报率的 11 步计算。

### 3. zzshare
| 项 | 内容 |
|---|---|
| 注册 | 可选（匿名频率低；官网免费领 Token） |
| 财务数据 | ✅ **5 张核心表**：`finance_valuation` / `finance_indicator` / `finance_income` / `finance_balance` / `finance_cash_flow` |
| 高级查询 | ✅ `finance_pit`（point-in-time 防未来函数）/ `finance_range` / `finance_stock` / `finance_latest` |
| 兼容性 | ✅ **接口规范兼容 Tushare**（`ts_code` 格式、字段名、`api.daily(ts_code=...)` 调用形式一致） |
| 分页 | 单股单次 1000 条，全市场 10000 条，支持 `offset` |
| 复权 | ✅ `adj='qfq'/'hfq'` |
| 限流 | 匿名较低；`stk_mins` 匿名 30 次/分；`rt_k` 需 Token 20 次/分 |
| MCP | ✅ 原生支持（`pip install "zzshare[mcp]"`） |
| 数据范围 | 行情 2005 年至今 |

**适配可行性**：**高**。虽然 40+ 接口里**主要是复盘/情绪/龙虎榜**（龟龟框架不需要），但**财务 5 张表齐全且兼容 Tushare 字段名**——这是关键。

⚠️ **风险**：作者是个人（zzquant），站点 `quant.zizizaizai.com` 新，**长期稳定性未知**；数据源未公开。

### 4. ashareapi
| 项 | 内容 |
|---|---|
| 注册 | 免费端点无需 Key |
| 财务数据 | ✅ `/v1/finance` **三表一次返回** |
| 端点 | 32（免费层）/ 49（付费层） |
| 代码格式 | ⚠️ **前缀式**（`sh600667`），与 Tushare 后缀式（`600667.SH`）不同 |
| 区间参数 | ⚠️ **不支持 start/end**，只能 `count=N` 取最近 N 根，本地过滤 |
| 字段名 | ⚠️ `ts_code→code`、`trade_date→date`、`close→last`、`vol→volume` |
| **不提供** | ❌ 新闻/公告全文、**指数日线**、**交易日历**、全量标的批量导出 |
| 免费限流 | **匿名 5 次/分**（解 PoW 挑战可 15 次/分），每次 ≤250 根 K 线，每天 ≤10 万条 |
| 付费 | ¥9.9/1万次 · ¥29.9/10万次 · ¥99/50万次 · ¥199/月不限量 |

**适配可行性**：**中**。三表能拿，但：
- **无交易日历** → 框架的 `trade_cal` 依赖断裂
- **无指数日线** → `yc_cb`（国债收益率 Rf）可能没有
- 代码格式 + 字段名 + 区间参数**三处都要改**

## 五、优劣势与可信度评级

### zzshare — 最优候选，但风险最高
- **优势**：财务 5 表齐全 + **Tushare 字段/调用形式兼容** → 改造成本最低；有 PIT 查询；有 MCP
- **劣势**：**个人项目**，站点新，无独立第三方验证；数据源不透明；40+ 接口里龟龟框架只需财务那 5 个
- **可信度**：**低-中**。PyPI 包真实存在（v0.4.12），文档详细，但**长期存续与数据准确性无法核实**

### AkShare — 最稳妥，但改造最累
- **优势**：社区最活跃、Star 最多、覆盖最广、久经验证
- **劣势**：爬虫本质 → **接口会随上游改版失效**（历史已多次发生）；字段命名混乱；敏感接口并发被封
- **可信度**：**高**（项目本身）。但**接口可用性是动态的**，今天的文档明天可能失效

### ashareapi — 商业产品，边界清晰
- **优势**：官方文档坦诚列出"能迁/不能迁"；有 MCP + Skill 集成；付费便宜
- **劣势**：**交易日历、指数日线缺失**，直接打断框架依赖；免费层 5 次/分**极慢**；字段/格式需改
- **可信度**：**中**。厂商自述，无法独立验证稳定性与数据质量；"免费无 Key"是获客手段

### Baostock — 不适配
- **优势**：免费、稳定、退市股完整、复权因子好
- **劣势**：**只有汇总财务指标，没有完整三表** → 龟龟框架的 11 步穿透回报率**无法执行**
- **可信度**：**高**（项目本身），但**对本案无用**

## 六、结论

**A股主轴：zzshare 优先，AkShare 兜底。**

理由：龟龟框架对**字段名粒度**依赖极重（应收、预收、折旧摊销、少数股东损益、资本化利息…），zzshare **字段级兼容 Tushare** 是决定性优势——改造成本从"写映射层"降到"改 client 类"。

**但必须留后手**：zzshare 是个人新项目，建议**加一层数据源抽象**，让 `TushareClient` 支持多后端（zzshare / AkShare）切换。

**港美股**：zzshare 不支持，仍需 Tushare 或 yfinance（框架已有 `yfinance_integration.py`）。

**⚠️ 所有候选的共同风险**：这些结论来自**社区文档和厂商自述**，无独立验证。价格/额度/可用性随时变动，实装前应逐一实测。
