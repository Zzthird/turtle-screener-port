| # | 差异点 | 说明 |

## 四、发现的阻塞项

### pi subagent 扩展 CLI 不兼容 ⚠️

```
Agent failed: option '-p, --port <port>' argument '--no-session' is invalid
```

**影响**：无法用 `subagent` 工具调 `quant` / `valuation` agent。

**这是扩展本身的问题**（examples 里的版本与当前 pi CLI 不匹配），非本项目的问题。

**绕行方案**：
- 方案 A：修扩展（改 `index.ts` 的参数）
- 方案 B：不用 subagent，把 agent 当作 prompt 直接在主会话执行
- 方案 C：用 `agents/*.md` 内容 + 主会话模型手动执行
