## 二、两家失败的确切原因（已定位，非代码缺陷）

### ① 格力电器 000651 — 年报本身没有母公司报表

```
扫描 248 页，含"母公司"字样的页均与报表无关
第 112 页起为：合并资产负债表 / 合并利润表 / 合并股东权益变动表
→ 全文无"母公司资产负债表"标题
```

**结论：数据源缺失，无法通过解析解决。**

### ② 招商银行 600036 — 银行报表结构与一般企业不同

```
无独立"本行资产负债表"标题页
采用 "本集团 | 本行" 双列对比形式（在附注内）
362 页，财报章节起始第 151 页
```

**结论：需专门适配银行类报表（本集团/本行双列），属结构性差异。**

## 三、开发中解决的技术问题

| # | 问题 | 案例 | 解决方案 |
|---|---|---|---|
| 1 | 跨页续表 | 伊利 89-92 页 | 向后扫描至多 4 页，遇下一报表标题即停 |
| 2 | 锚点前缀 | `减：营业成本`、`一、营业收入` | 归一化去前缀 |
| 3 | 目录页误命中 | 五粮液第 53 页 | `_is_toc_page()` 点线+页码密度判定 |
| 4 | 标题在句子中被提及 | 神华第 129 页（审计报告） | 标题须独占一行且长度受限 |
| 5 | 无年份表头 | 太阳纸业「期末余额/期初余额」 | 占位符 T/T-1 → 从页面文本回填 |
| 6 | 科目列偏移 | 太阳纸业第一列全空 | `_label_col()` 自动定位科目列 |
| 7 | **无框线表格** | 中国神华 | **多策略提取：lines 失败 → text 策略** |
| 8 | 母公司标题变体 | 带「（续）」 | 归一化空白/分隔符 |
| 9 | **单位不一致** | 神华用百万元 | `_detect_unit()` 识别并归一化到元 |

**其中 #7（无框线表格）最关键** —— pdfplumber 默认 `lines` 策略对神华返回 0 张表，改用 `text` 策略后成功。

## 四、可用性结论

| 场景 | 支持 |
|---|---|
| 一般工商企业（制造业/消费品/能源） | ✅ **可用** |
| 报表有框线 | ✅ |
| 报表无框线 | ✅（text 策略） |
| 跨页报表 | ✅ |
| 单位非元（百万元/万元） | ✅（自动归一化） |
| **公司未披露母公司报表** | ❌ 数据源限制 |
| **银行/保险等金融业** | ❌ 需专门适配 |
| 扫描件 PDF | ❌ 需 OCR（未测） |

**建议**：非金融 A 股可用，覆盖率约 71%；失败时**优雅降级**（标注缺失，不中止分析）。
