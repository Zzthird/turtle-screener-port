## 步骤 1：Owner Earnings

> 查表：§17.12 G 系数网格（表头：C = 11,565 | D = 4,072 | F = 1.63），**不重算**。

**网格表头取值（直接引用）**：C = 11,565 百万元，D = 4,072 百万元（精确值 4,072.40，见下），F = 1.63

**选档：G = 1.0（档位标注「轻资产」上沿，即「中等资产」下沿）→ H = 4,072，OE = 11,565 百万元**

理由（结合资产密度）：
1. **产品属性 + 锚点表一致**：伊利为品牌乳制品消费品（液体乳/奶粉/冷饮），品牌与渠道是主要价值来源，但**自有产能 + 冷链体系**使其非纯轻资产 → 按选择锚点「轻资产 0.7–1.0 / 中等 1.0–1.3」取该类区间**上沿 G = 1.0**，与 `judgment_examples_turtle.md` 锚点表「**伊利股份（600887）乳制品制造 G = 1.0：中等，生产线需持续更新但非重资产**」**完全一致** ✓。
2. **维持性下限原则**：G = 1.0 意味着维持性 capex 至少覆盖全部折旧摊销 D = 4,072（产线/设备/冷链更新）。2025 实际资本开支 3,036.64 < D（当年 capex/D&A = 0.68）→ 用 G = 1.0 已属**稳健下限**（实际当期 capex 低于该假定）。
3. **不采用 F = 1.63 的理由**：F 被 **2021–2023 扩产高峰**拉高（capex 6,682.73 / 6,646.11 / 6,955.60；当年 capex/D&A = 2.03 / 1.71 / 1.63）。若按 F 计 H = 6,637 百万元（OE 仅 ≈ 9,000），与 2024–2025 资本开支已回落（capex/D&A = 0.89 / 0.68）的经营现实不符，属过度严厉。
4. **压力对照（不改变选档）**：G = 1.2 → OE = 10,751 百万元；G = 1.4 → OE = 9,936 百万元。
