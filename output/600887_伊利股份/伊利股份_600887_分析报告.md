### 1. 商业模式与资本特征

**结论：模式清晰且经周期验证 —— "全国化渠道 + 品牌矩阵 + 自建产能"的乳品制造与分销商，收入质量高、先款后货、资本开支已过峰；但增长已由"量价齐升"切换为"结构升级 + 成本红利"，收入端复合增速仅 1.22%。**

- **一句话商业模式**：以自建/控股产能（全球 81 个生产基地、综合产能 1,600 余万吨/年）生产液态奶、奶粉、冷饮等乳制品，通过经销商体系（FY2024 经销收入占主营 97.1%：1,107.96 ÷ 1,141.21 亿元）触达全国终端，赚取品牌与规模带来的制造+分销价差；六大事业部独立运营。
- **收入质量分解（FY2024 口径）**

### 3. 外部环境

**结论：弱周期、非政策依赖型行业，当前处于"原奶供给过剩向再平衡过渡 + 消费需求低位"的中段位置；监管风险低，但对食品安全事件的尾部风险高度敏感。**

1. **周期性**：`cyclicality = 弱周期`、`cycle_position = 中段`。FY2024 营收 −8.24%、FY2025 +0.21%（需求弱周期 + 原奶 3–4 年价格周期叠加）；原奶价格下行推动 FY2024 主营毛利率 +1.31pct 至 34.03%，FY2025 进一步升至 34.74%。
2. **政策与监管**：政策方向支持（提振消费、肉牛奶牛生产稳定、复原乳标识规范、中央一号文件）；政策依赖度低（政府补助仅占归母 11.6%）；`regulatory_risk = 低`（尾部为食品安全事件而非政策变动）。

```
门槛 II           = 3.70%   （A股：max(3.5%, Rf + 2%)）
精算穿透回报率 GG = 6.20%   （§17.11 表B AA_2y ★ @ Q=0）
GG vs II          = 达标（+2.50 pct）
```

> 口径提示（透明化）：若直接以 §14 最新值 1.7170% 计算，II = 3.72%，安全边际为 **+2.48 pct**（较 +2.50 微降 0.02 pct），**不改变任何结论**。本报告全程采用 §17 预计算的 II = 3.70%（约束：有网格不重算）。

**步骤 3：安全边际与仓位**

```

周期性修正（仅强周期适用；定性报告 D3：cyclicality = 弱周期、cycle_position = 中段）
  → 非强周期 → 不调整（II 维持 3.70%）
修正后安全边际 KK = +2.50 pct
保守交叉（AA_all）：KK_保守 = 4.78% − 3.70% = +1.08 pct
```

| 条件 | 仓位建议 | 本案是否适用 |

## 投资论点卡（Thesis Card）

### 10.1 投资论点摘要

**核心论点**：伊利是"模式已验证、弱周期、先款后货、资本开支已过峰"的全国乳业龙头，FY2025 归母 11,565.17 百万元、FCF 11,307.28 百万元、支付率 75.81%，按 §17.11 精算 GG = 6.20% 高于门槛 3.70%（+2.50 pct），保守交叉口径 4.78% 亦高于门槛；现价 28.10 元较目标买入价 47.07 元折让 40.32%，估值本身不贵。**但买入的核心理由不足**：外推可信度「低」（利润口径调整幅度 25.7% + λ 失效），FY2025 利润高增 98.8% 由减值基数修复解释且明细缺源，分红覆盖已降至 0.94×。因此裁决 **观察**，等待可核实的分红覆盖与利润质量证据后再建仓。

**买入理由**（观察转买入的门槛证据，≤5 条，每条含具体数据）：
1. FCF 五年连续为正（8,844.79 → 11,307.28 百万元），5 年累计 56,022.46 百万元，覆盖累计宣告分红 36,687.10 百万元的 **1.53×** —— 分配能力真实。
2. 现金收款模式优越：应收账款仅 28.78 亿元（约 9.1 天）、合同负债 105.64–120.73 亿元、OCF/归母 5 年均值 1.75。
